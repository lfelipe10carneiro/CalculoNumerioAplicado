# CalculoNumerioAplicado

Repositório dedicado à todas as atividades, projetos e códigos feitos no curso de cálculo numérico aplicado.

Para cada pasta diferente, tem seu próprio README.MD com informações sobre o relatório, se for Atividade para Casa (ApC), ou código, se for Programa para casa (PPC).

O objetivo desse README.MD é passar toda explicação que ajude ao melhor entendimento do que se trata esse repositório, bem como a organização adotada nele.

Em princípio, todos os PPCs serão em Python, e no caso de baixar para executar os códigos, ou replicar em sua própria máquina pessoal, 
é importante que seja feito o download das seguintes bibliotecas que são importadas nos códigos: Numpy e Matplotlib.

Dificilmente alguma outra biblioteca será utilizada, pois a ideia dos programas é criar os laços que resolvem o problema pedido para cada método,
com isso, exigindo uma codificação mais manual que permite basicamente somente essas bibliotecas.
