# Programa para casa 3

O PPC3 tem como objetivo propor um problema de distribuição de temperatura, em uma parede plana, no contexto 1D. Para o problema, as considerações são: regime transiente, sem geração de energia interna, simetria adiabática e condição de contorno de convecção.

Nesse problema estamos buscando modelar a distribuição transiente de calor em uma pastilha de combustível nuclear (Dióxido de Urânio) sujeita a resfriamento convectivo e geração interna de energia. 

Com isso, o problema exige a prática dos conceitos teóricos vistos e aplicados analiticamente na ApC3, de modo que encontremos a solução do problema numericamente. Keep chill!
