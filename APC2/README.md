# Atividade para casa 2

A APC2 tem como objetivo desenvolver a compreensão analítica de sistemas dinâmicos com múltiplos graus de liberdade, bem como estabelecer a conexão entre modelagem física e a estrutura matemática do problema.

Para isso, foi utilizado de exemplo um sistema massa-mola-amortecedor com N graus de liberdade, composto por massas acopladas por molas e amortecedores com propriedades distintas. 

Para entender como se desenvolveu essa atividade e todos os detalhes da mesma, ler a atividade. Keep chill!
