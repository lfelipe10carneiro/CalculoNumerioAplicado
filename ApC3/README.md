# Atividade para casa 3

O APC3 tem como objetivo compreensão analítica das ideias e conceitos de conteúdos relacionados à métodos numéricos vistos em sala, sendo eles, nessa atividade, especificamente:

	- Decomposição L.U.;
	- Algoritmo de Thomas;
	- Decomposição de Cholesky;
	- Método de Gauss-Seidel;
	
Com isso, pode-se desenvolver a compreensão desses diferentes métodos e a resolução de cada um em cima do exercício pedido na atividade se encontra no PDF. Keep chill!
