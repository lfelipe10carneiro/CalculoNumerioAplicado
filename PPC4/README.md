# Programa para casa 4



O PPC4 tem como objetivo implementar e comparar computacionalmente dois métodos de otimização multidimensional (Método do Aclive Máximo e Método dos Gradientes Conjugados), na busca pelo ponto máximo de uma função de duas variáveis.



O programa permite, ao comparar os dois métodos, mostrar que enquanto o Método do Aclive Máximo fica andando em zigue-zague até convergir, o algoritmo de Fletcher-Reeves (Método dos Gradientes Conjugados) aproveita do histórico de busca.



Ao executar o programa, é possível visualizar o comportamento dos métodos até o valor final pelo gráfico plotado, com isso, confirmando como reagem até encontrar o resultado.
